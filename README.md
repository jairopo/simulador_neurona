# Simulación de una neurona en Streamlit

Este proyecto es una simulación interactiva de una neurona con entradas, pesos, un sesgo y una función de activación, creada con **Streamlit**. 

A través de una interfaz gráfica, el usuario puede modificar el peso, las entradas y calcular la salida de la neurona.
